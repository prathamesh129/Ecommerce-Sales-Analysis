# Ecommerce Sales Analysis

## Project Overview

A SQL-based data analysis project focused on analyzing e-commerce sales data to identify customer behavior, product performance, sales trends, and business insights using advanced SQL queries.

## Tech Stack

- MySQL
- MySQL Workbench

## Data Source

Dataset: E-commerce Sales Dataset downloaded from Kaggle.

The dataset contains order information, product details, customer data, and sales targets. It was used to perform business analysis using SQL.

## Project Features

- Sales Analysis
- Customer Analysis
- Product Performance
- Category-wise Analysis
- State-wise Sales Analysis
- SQL Business Queries
- CTEs & Window Functions

## Key Insights

- Analyzed sales and profit performance.
- Identified top-performing customers and product categories.
- Compared sales across different states and cities.
- Used CTEs, subqueries, and window functions to generate business insights.
